# V-JEPA 2 / V-JEPA 2-AC 深读

核查日期：2026-09-25。固定版本：[2506.09985v1](https://arxiv.org/abs/2506.09985v1)，2025-06-11；[原文 PDF](https://arxiv.org/pdf/2506.09985v1)，[正文与附录 TeX（论文入口）](https://arxiv.org/abs/2506.09985v1)。已阅读方法、机器人实验、附录 B；以下为作者报告，未运行复现。

## 1. 为什么选它，怎样归类

这是 **latent world model + model predictive control（MPC）** 的代表，补足视频生成式 WAM 之外的路线。V-JEPA 2 是视频表征模型；真正用于机器人控制的是后训练得到的 **V-JEPA 2-AC**。它根据候选动作预测未来特征，再搜索动作；没有直接接受语言并输出动作的 VLA 接口，也不生成可观看的未来 RGB 视频。

其后续采用证据是 [JEPA-WMs 研究](https://arxiv.org/abs/2512.24497)明确将 V-JEPA-2-AC 与 DINO-WM 作为既有基线。这个证据支持其在 latent planning 分支的代表性，不等价于“当前 WAM 控制效果最好”。

## 2. 架构：两个阶段必须分开

### 无动作视频预训练

给视频遮挡一部分时空块，可见部分经过 encoder，predictor 预测被遮挡位置的目标特征；目标来自 EMA target encoder，停止梯度。训练匹配的是特征的 L1 距离，并非像素重建。输入使用时空 tubelets，3D RoPE 表示时间、高度、宽度三个索引；**这里的 3D 不是机器人世界坐标或三维几何重建**。VM22M 包含约 22M 视频/图像样本，视频超过百万小时，来源含 SSv2、Kinetics、HowTo100M、YT-Temporal-1B、ImageNet；这些是基础模型预训练，不应省略后再说“只用 62 小时训练世界模型”。证据：§2、附录 A。

### 动作条件后训练

冻结预训练 ViT-g encoder，逐帧产生 `z_k ∈ R^(16×16×1408)`。另训练约 300M 的 Transformer predictor：24 层、16 heads、hidden 1024。

输入交错排列 `(a_k, s_k, z_k)`。`s_k` 是机器人基座坐标系下末端 7D 状态：xyz、extrinsic Euler 角、夹爪；`a_k` 由相邻帧状态差分得到。block-causal attention 允许同一步全部特征互看，并访问过去，禁止访问未来。输出是下一帧特征，而不是动作。证据：§3.1。

## 3. 训练目标、数据与配方

后训练损失可概括为：

`L_AC = L1(teacher-forced next latent, target latent) + L1(two-step rollout latent, target latent)`。

第一项始终读真实历史编码；第二项把上一步预测再喂回 predictor，训练短程自回归稳定性。论文示意图画了 4 步，**实际 rollout loss 用 2 步**，不能照图推断训练长度。只更新 predictor，encoder 冻结。

| 项目 | 作者设置 | 原文位置 |
|---|---|---|
| 机器人数据 | DROID 子集；剔除不足 4 秒轨迹后少于 62 小时 | §3.1、附录 B.1 |
| clip | 4 秒、4 fps、16 帧、256² | 同上 |
| 输入相机 | 仅左侧外部相机 | B.1 |
| 优化器 | AdamW，weight decay 0.04，batch 256 | B.1 |
| 学习率 | 7.5e-5→4.25e-4，4500 步 warmup，85500 步恒定，4500 步衰减至 0 | B.1 |
| 增强 | random-resize-crop，宽高比 0.75–1.35 | §3.1/B.1 |

作者的 **unlabeled** 是“不用任务类别、奖励、成败标签”，仍然使用末端状态信号构造动作，不能理解为无动作信息的人类视频学习。B.1 还明确报告：左右相机一起训练、却不给相机位置条件，会使效果下降。这是本项目应重点关注的负面证据。

基础视频模型另有大规模预训练和渐进增加分辨率/时长的配方；机器人后训练表中的 batch 和步数不能当作整个 V-JEPA 2 的训练成本。论文关于直接高分辨率长片段训练的 GPU-years 估算，也不能直接写成 AC 模型实耗。

## 4. 部署：预测模型怎样变成策略

1. 用 encoder 编码当前观察和目标图像。
2. 采样候选动作，用 AC predictor 展开，计算最终预测特征与目标特征的 L1 距离。
3. 用 **Cross-Entropy Method（CEM）** 搜索低代价动作。此处 CEM 是采样优化算法，不是神经网络的交叉熵训练损失。
4. 只执行第一个动作，读取真实观察，重新搜索。

附录 B.2 使用 800 个候选、10 次 refinement、每次保留 top 10，**planning horizon=1**。抓取/拿着物体移动用单目标；pick-and-place 额外给两个中间目标，分别在 4、10、4 步后切换。它展示的是有图像子目标辅助的闭环控制，不能直接解释成长时程自主任务分解。

## 5. 评测究竟证明什么

两个新实验室的 Franka + RobotiQ，任务不再额外收集训练数据；Table 2 每个实验室/任务条目 10 trials。下表是两个实验室的平均成功率，不是大规模任务全集平均：

| 方法 | Reach | Grasp cup / box | Reach with cup / box | Pick-place cup / box |
|---|---:|---:|---:|---:|
| Octo | 100% | 15% / 0% | 15% / 70% | 15% / 10% |
| V-JEPA 2-AC | 100% | 65% / 25% | 75% / 75% | 80% / 65% |

Table 3 比较的是当时的 **Cosmos Predict1 7B**，不是 2026 年 Cosmos Policy。在 RTX4090 上，Cosmos 的 80 个候选/10 次 refinement/horizon 1 约 4 分钟每动作；V-JEPA 2-AC 用 800 候选约 **16 秒每动作**。这证明该设置下 latent planning 更便宜，但距离 Fast-WAM 的百毫秒动作块生成仍有很大差别；搜索次数、目标形式和任务也不同。

## 6. 跨视角：最值得精读的失败机制

正文 Limitations 指出模型必须从单目图像隐式推断基座动作坐标轴；机器人基座不在画面内时，映射可能不明确。作者实际尝试不同相机位置，选择一个工作较好的位置后固定。

附录 B.4 在约 35°–85° 相机位置上分析：每个位置收集 201 步平面随机运动，比较真实位移与模型反推的位移。线性校正后平均绝对预测误差约 1.6cm，真实 delta pose 约 5cm；误差主要呈相机相关旋转。**“无显式标定可控制”并不推出“对任意相机位置不敏感”。** 作者讨论用校正矩阵补偿，但没有提供跨所有视角闭环成功率都保持不变的证明。

对本项目的启发（阅读推断，未实验验证）：一致性约束前必须明确动作所在坐标系；同一基座动作在两个相机里投影不同，不能直接匹配图像位移。还应区分表征预测误差、动作坐标变换误差、最终闭环失败。

## 7. 资产、复现缺口与阅读顺序

[官方仓库](https://github.com/facebookresearch/vjepa2)提供模型、训练配置和代码，包括 AC 与 energy-landscape 示例。当前仓库也包含 **2026 年 V-JEPA 2.1**；本笔记固定 2025 年 v1，不混入后继配方。仅核查公开入口，未验证机器人硬件部署全链路。

建议先读 §3.1 的两个损失→§3.2 的 CEM→Table 2/3→B.1/B.2/B.4→回头补 §2 预训练。复现优先确认：DROID 子集筛法、相机选择、动作差分频率、图像目标/子目标制作、候选动作约束与计时范围。它适合学习“世界模型用于搜索”，不宜直接当作 Fast-WAM 的同接口替换基线。
