# OpenVLA 阅读笔记

核验日期：2026-09-25。论文：**OpenVLA: An Open-Source Vision-Language-Action Model**，Moo Jin Kim 等；固定阅读 [arXiv:2406.09246v3](https://arxiv.org/html/2406.09246v3)（2024-09-05）。**状态：读过方法、实验和 LIBERO 附录，未复现。本文指原版 OpenVLA，不把后来的 OFT/FAST 改动算入原模型。**

## 一句话与架构

OpenVLA 把预训练视觉语言模型适配为机器人策略：图像和任务指令输入，输出表示动作的离散 token，再解码为机器人命令。它保留了语言模型的自回归预测方式。[作者项目页](https://openvla.github.io/)

| 部分 | 原版配置 |
|---|---|
| 输入 | 单张当前第三人称 RGB 图像（224×224）和语言指令 |
| 视觉 | 同一图像分别经过 DINOv2、SigLIP，特征按通道拼接 |
| 连接与语言骨干 | 两层 MLP projector；Prismatic 初始化的 Llama 2 7B |
| 输出 | 单步 7 维末端执行器控制动作：位置、旋转、夹爪 |
| 动作表示 | 每个维度独立分为 256 桶，范围由训练数据第 1/99 分位数决定 |
| 损失 | 自回归 next-token 交叉熵，只对动作 token 计算 |

**两个视觉编码器不等于两台相机。** 原版也没有动作块、观测历史或本体状态输入；这些能力不能从后续仓库更新倒推到论文。离散桶替换语言词表中低频 token，预测后需按目标数据集的统计量反归一化。[论文 §3.1–3.4、图 2](https://arxiv.org/html/2406.09246v3#S3)、[官方推理接口](https://github.com/openvla/openvla#getting-started)

## 数据与训练的三个层次

先有图像/文本骨干预训练，再有 Prismatic 的视觉语言训练，最后用筛选后的 Open X-Embodiment 机器人演示做动作训练。机器人数据为约 **970k 轨迹**，不是 970k 图像。选取具有第三人称相机、单臂末端控制的数据；不能理解为不加处理就吃入全部 OpenX 数据。原论文还说明 DROID 在训练末段被移除。[论文 §3.3](https://arxiv.org/html/2406.09246v3#S3.SS3)、[官方项目页 The OpenVLA Model](https://openvla.github.io/)

教学理解：模型把“伸手抓红杯子”转成七个量化控制量。交叉熵正确率只说明这些桶预测得是否相近；最终仍须闭环执行，检查是否抓对物体并完成任务。

## 已核实实验与数字

原论文既有真实机器人直接评测，也有用目标任务演示微调后的评测；两者不可混称零样本。真实直接评测采用 WidowX 与 Google robot，相同初态做 A/B 比较；前者 17 任务×10 次，后者 12 任务×5 次。[论文 §5.1](https://arxiv.org/html/2406.09246v3#S5.SS1)

更便于以后复核的一组数字是**表 12 的 LIBERO 微调结果**：

| 方法（均按该论文数据处理与评测） | Spatial | Object | Goal | Long | 平均 |
|---|---:|---:|---:|---:|---:|
| OpenVLA，LoRA 微调 | 84.7% | 88.4% | 79.2% | 53.7% | 76.5% |
| Diffusion Policy，从头训练 | 78.3% | 92.5% | 68.3% | 50.5% | 72.4% |

每个 suite 独立训练模型，包含 10 个任务；每个统计量为 3 个种子×500 trials。OpenVLA 平均标准误为 ±0.6%，DP 为 ±0.7%。作者重渲染图像、清除 no-op 和回放失败演示，并仅用静态第三人称相机；这里的 DP 加有语言条件，不是原始 DP 论文的同一实验。**这些结果不能与其它论文只因都写 LIBERO 就直接拼榜。**[论文附录 E、表 12](https://arxiv.org/html/2406.09246v3#A5)

作者项目页也呈现反例：DP 在较窄、要求精确运动的单指令任务上仍有优势；OpenVLA 在多物体、多指令任务中更突出。这比一句“全面优于 DP”更准确。[作者项目页 Data-Efficient Adaptation](https://openvla.github.io/)

## 成本与开放边界

论文 §3.5 报告最终训练为 64 A100×14 天，约 21,500 A100 小时；未加速 BF16 推理约需 15GB 显存、RTX 4090 上约 6Hz。项目页写 15 天，本文成本口径以固定版本论文为准。不要把从已有权重 LoRA 微调的成本当作完整预训练成本。[论文 §3.5](https://arxiv.org/html/2406.09246v3#S3.SS5)、[项目页](https://openvla.github.io/)

官方发布权重、训练及评测代码；代码为 MIT，模型继承 Llama 2 许可要求。当前 README 给出的普通 LoRA 微调显存下限约 27GB，取决于 batch size；并建议核对版本与输入/动作处理。开放模型仍依赖上游预训练，不能据此声称所有上游训练数据都能完整重建。[官方仓库：模型与许可、微调、Troubleshooting](https://github.com/openvla/openvla)

## 对跨视角一致性的意义：本项目分析

OpenVLA 适合作为“单视角视觉语义能做到什么”的参照。DINOv2 增强空间特征并不构成相机间几何一致性约束。多视角输入、视角扰动、显式一致性损失应分别作为改动报告；不能一次全部加入后把提升归因于其中一项。

需要追问的可检验问题是：同一个机器人状态，换外部相机后，动作是否仍在同一物理坐标系中合理？语言 grounding 与视角不变性也要分开评估。本笔记没有实验证明 OpenVLA 存在或解决了这一问题。
