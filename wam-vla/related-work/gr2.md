# GR-2：把视频预训练、动作块和真实机器人系统一起扩大

核实日期：2026-09-25。**GR-2: A Generative Video-Language-Action Model with Web-Scale Knowledge for Robot Manipulation**，ByteDance Research；[arXiv:2410.06158v1](https://arxiv.org/abs/2410.06158v1)，2024-10-08 技术报告。已读正文及本地 PDF/TeX；以下均为作者报告，**未复现**。

## 1. 为什么值得读

GR-2 自称 **generative video-language-action model**，是 GR-1 的直接后继（§1）。它展示了视频—动作路线如何从仿真和少量桌面技能扩到真实多任务、复杂干扰和料箱抓取；对研究 WAM 的价值在于数据规模、模型接口和机器人部署之间的联系，不能只记住摘要的成功率。

其代表性依据是可核实的研究谱系和实验范围：明确延续 ICLR 2024 GR-1，在同一 CALVIN 评测和自己的真机设置中比较两代模型（§3.1–3.3），并报告模型规模实验（§3.5）。这不是独立第三方验证，也不是引用量排名；原文没有自称跨视角一致性方法。

后续采用证据：[Fast-WAM v2 §2](https://arxiv.org/abs/2603.16666v2)在通过未来视觉预测学习控制的研究脉络中直接引用GR-2；Fast-WAM v2的相关工作正文 的引用键为 `cheang2024gr2generativevideolanguageactionmodel`。这确认它进入了后续WAM问题讨论，但不等于后续论文复现其全部结果。

## 2. 输入输出：离散的是图像，动作仍为连续轨迹

§2 给出 `a[t:t+k] = π(l, o[t−h:t], s[t−h:t])`。为避免端点记法歧义，可记实际输入帧数为 `Tobs`、输出动作数为 `Ta`：

| 张量/语义 | 输入或输出 |
|---|---|
| 语言 `l` | 冻结 CLIP 文本编码器提供特征 |
| 相机历史 `O` | 可概括为 `B×Tobs×V×3×H×W`；真机 V=2，固定头部视角和腕部视角 |
| 图像离散码 `z` | 冻结 VQGAN 将每张图编码成 codebook 索引网格，再交给 GPT |
| 状态 `s` | 末端位置、旋转和二值夹爪，经可训练线性层编码 |
| 未来图像 | 预测每路未来图像的离散码，交给 VQGAN decoder |
| 动作块 `A` | `B×Ta×da` 的连续笛卡尔空间动作轨迹，经 conditional VAE 生成 |

这些 shape 表达的是语义轴，不是论文已公布的全部常数：**v1 没给足 `Tobs`、`Ta`、图像分辨率、码本网格和旋转参数化的实现值**。不能从 GR-1 的10帧、七维增量动作，或 ACT 的默认 horizon 直接移植数值。VQGAN 是图像 tokenizer；cVAE 是动作生成器；二者都不等于 FAST 的动作 tokenizer，更不是 Fast-WAM。

## 3. 从预训练到执行的可确认路径

**视频预训练。** GPT 接收文本与图像历史，预测未来离散视觉码，解码后得到视频。VQGAN 在互联网和机器人图像上训练后冻结；文本编码器也冻结。数据经过手部筛选、重描述，以增加操作相关内容，而不是不加选择地把所有网络视频输入模型（§2.1）。

**机器人微调。** 单视角预训练接口扩展到多相机历史与机器人状态，联合预测各视角未来画面和动作轨迹；动作头使用 cVAE。作者说明动作块对平滑性和实时性很重要，但 v1 没有给出“只改动作块”的量化消融，所以不能把 GR-2 对 GR-1 的全部增益归于这一项。

**视觉计划与动作。** §3.4 说明先生成视觉轨迹，再据此推断动作轨迹，并展示预测视频与真实 rollout 对齐。可确认的高层信息流是“语言/观察 → 未来视觉表征 → 动作生成”，但 v1 没有像 GR-1 或 Fast-WAM 那样完整列出 attention mask：历史与未来 token 如何互读、不同相机码的排列、action query 是否读预测 token，均不足以仅凭正文还原。不能把 GR-1 的“所有预测查询禁止作为 key/value”直接当成 GR-2 的机制。

**损失也有缺口。** 论文描述离散视觉码自回归预测与 cVAE 动作学习，却没有列出完整优化目标、CE/重建/KL 的确切形式和系数。一般 cVAE 可用“重建项 + KL 正则”理解，但那是背景知识，**不是本报告已核实的 GR-2 loss 公式**。也未公开训练期后验、测试期潜变量采样或置零策略，故不据此伪造推理算法。

**实际机器人还有控制层。** 生成的笛卡尔轨迹先做平滑和连续性优化，再由 Whole-Body Control 转为关节动作，并考虑碰撞约束和可操作性；Kinova Gen3 七自由度机械臂搭配 Robotiq 2F-85 夹爪（§2.2）。**200 Hz 是低层控制执行频率，不是 GPT/cVAE 每秒推理200次**。这层系统工程参与最终效果，不能把整个闭环成绩看成神经网络单独的性能。

## 4. 数据、规模和真实评测

§2.1 预训练共38M视频片段、约50B tokens，来源包括 HowTo100M、Ego4D、Something-Something V2、EPIC-KITCHENS、Kinetics-700，以及 RT-1、Bridge 机器人数据。注意此混合并非纯人类无动作数据，也不能将原始数据集体量直接相加得到作者筛选后的体量。

§3.1 桌面数据实际是 **105个任务、约40,000条轨迹、平均约400条/任务**，覆盖抓、放、揭盖、盖盖、开、关、按、倒八类技能。约5000条/平均50条只是取1/8的低数据配置。摘要、引言与主结果常把这些数字靠近放置，必须避免误写“5000条训练即达到97.7%”。

数据增强单独标 `w/ DA`：扩散模型插入物体，SAM 分离背景，视频生成模型传播修改，同时保留机器人动作。它改变了训练数据分布；带增强和不带增强不是同一个设置。

| v1 §3.1、图6，真机成功率 | 报告值 | 解释 |
|---|---:|---|
| GR-2，400/任务，Simple | 97.7% | 训练近分布的105项任务 |
| GR-2，50/任务，Simple | 73.9% | 低数据设置，不能冒用上一行 |
| GR-2，Unseen Backgrounds / Environments | 71.4% / 71.7% | 桌布、厨房背景及场景干扰变化 |
| GR-2，Unseen Manipulation | 55.8% | 包括新实例和新类别，仍有抓取和目标识别失败 |
| GR-2 w/ DA，Unseen Environments | 87.0% | 包含额外数据增强 |
| GR-2 w/ DA，三种泛化设置平均 | 74.7% | 不含 Simple/Distractor 的平均 |

本版本没有完整交代图6每格评测次数、置信区间和按任务/按 trial 加权细节，不能由百分数推算精确成功次数。未见环境也没有等价于移动相机的单独评测。

**料箱抓取是另一套训练数据。** §3.2 使用约94,000条轨迹和55种训练物体；评测共122种物体，其中67种未见。普通箱内为5–9件，更拥挤为12–17件。图9和正文报告四设置平均成功率 GR-1 33.3%、GR-2 79.0%；这是“把任意物体从右箱搬到左箱”的任务，不能与105类语言任务平均混算，也不是机器人已经完成工厂连续运行验证。

**CALVIN 有公开协议。** §3.3、图10在 ABCD→D 上训练，评测1000条五任务指令链；GR-2 第一项 `.986`、完整五项 `.859`、平均链长 `4.64`，GR-1 对应 `.949/.731/4.21`。这比摘要中的单项成功率更完整，但本报告未提供 ABC→D 的同样结果，不宜替它声称跨环境 SOTA。

## 5. 消融、预算和复现边界

§3.5 报告可训练参数为30M/95M/312M/719M的 S/B/L/XL 四档，验证视频损失随规模降低，机器人成功率总体随规模改善。默认 B 的总参数为230M、可训练95M（§3开头）。规模实验又明确：预训练混入域内机器人视频，动作微调时冻结预训练参数。这个冻结设置需与默认多任务实验区分；不能仅凭一段话推定每个实验都训练同一参数集合。

图11给出规模相关趋势，不是把视频预训练量、参数、训练 FLOPs 全部锁定后的单变量因果证明。GR-2 还同时改变视觉离散化、动作块、预训练体量、数据增强和控制系统；与 GR-1 的总差异不足以证明某一个改动独立贡献。报告没有完整训练steps、batch、学习率、GPU数、GPU-hours 或神经策略端到端延迟，因此无法给出可信重训预算，也不能与 Fast-WAM 的毫秒数直接排序。

截至核实日，[作者项目入口](https://gr2-manipulation.github.io/)与论文可访问，但动态项目页没有在本次核查中提供可确认的完整训练代码/权重/数据发布入口；未找到能够验证上述 pipeline 的官方 GR-2 仓库。应记为**未核实公开**，而非凭搜索结果断言永未开源。GR-1 开源不等于 GR-2 开源，网上同名实现也应核对作者来源。机器人私有数据、VQGAN训练混合和筛选重描述过程是重大复现缺口。

## 6. 与 Fast-WAM、跨视角研究的关系

GR-2 强调预测视频与动作轨迹对齐；[Fast-WAM v2](https://arxiv.org/abs/2603.16666v2)则在固定骨干和配方下，控制动作不读取未来视频，检验测试时移除未来生成的效果。前者的可视化对齐不能证明后者的受控结论，也不能证明动作一定需要显式未来像素；需要同一实现中的路径删除和延迟消融。

GR-2 确实具备多视角输入和多视角未来输出，比仅用单相机的基线更贴近本课题。但是它没有报告重投影误差、三维状态一致性或 view-drop 对照；两路视频看起来合理不足以证明同一物体在两相机中满足同一几何状态。潜在研究方向是给同一机器人动作对应的双视角预测增加几何或对象状态约束，并同时检查成功率和跨视角误差；这是本项目建议，不是已验证结果。
