# Genie Envisioner：多视图世界模型、策略与神经仿真器

> **阅读状态**：正文与数字按本地 **2508.05635v3** PDF/TeX 核验（v3：2025-11-04；首版 2025-08-07）；未复现。已核实 [ICLR 2026 发表版本](https://openreview.net/pdf?id=fHLtSxDFKC)存在，但不将该会议版的新增内容混入本次固定 arXiv 版本。资源核查日：2026-09-25。

## 1. 先把平台中的三个模型分清

Genie Envisioner（GE）不是一个单独的动作网络。**GE-Base** 学习语言条件多视图未来视频；**GE-Act** 从该骨干的预测性视觉特征生成机器人动作；**GE-Sim** 则给定机器人动作生成后续观测，用作神经仿真器。EWMBench 用来评价生成视频。后两者方向不同：策略输出动作，仿真器接收动作，不能把其训练信号与相机要求混写。

它值得读的原因是，在同一项目中展示了“视频先验怎么迁移到策略”和“多个相机怎么交流”的具体设计。[DreamZero](dreamzero.md) 引言明确将 GE 列为视频先验改善动作学习样本效率的先行工作；[Fast-WAM](fast-wam.md) related work 也引用 `ge2025`。这证明它已进入后续 WAM 技术讨论，不代表后续论文复现了全部 GE 实验。

## 2. GE-Base：三路视频如何合成一个世界预测

输入包括头部、左腕、右腕三路同步 RGB，稀疏历史帧与语言。每个视图独立经过共享 VAE；视觉 token 加二维 RoPE 和可学习视图嵌入，语言经过冻结 T5-XXL，通过 cross-attention 注入 DiT。当前/历史视觉条件与各视图噪声共同预测下一视频块，再自回归生成后续块。

跨视角机制是将部分层的空间注意力从 \((H,W)\) 扩成 \((N,H,W)\)：选定的 DiT 层允许三个视图互相读取，其余层将视图维并入 batch，分别计算，以节省开销。这是**显式跨视图特征通信**。原文没有给出相机射线、深度重投影或多视图几何一致性损失；“数据从标定相机采集”不等于模型使用标定参数。视图 embedding 也未证明能泛化到任意新相机。

面向策略的 GE-Base 使用 LTX-Video 2B；GE-Sim 另有 COSMOS2 2B 变体。机器人预训练数据为 AgiBot-World-Beta，约百万 episodes、2,967 小时。这是平台的机器人适配数据，不应把使用预训练视频骨干描述成从未接触通用视频。

GE-Base 两阶段训练保持视频编码/解码器冻结：第一阶段 MR 采样 57 帧，帧率随机 3–30 Hz，另有四幅稀疏历史帧，编码为八帧 latent；32 张 A100 约七天。第二阶段 LF 使用 5 Hz 的九帧片段和四幅历史帧，压成两帧 latent；32 张 A100 约三天。目的分别是适应机器人动态，以及减少动作学习所需的视觉时间分辨率。正文给出去噪训练描述，没有完整展开可据以重建所有权重和采样约定的统一损失公式。

## 3. GE-Act：保留预测性表示，避免完整视频生成

在 GE-Base 旁增加约 **160M** 的动作 DiT，层数与视觉骨干对齐、隐藏维更小。第 \(i\) 层动作 token 通过 cross-attention 读取视觉层特征 \(v_i\)，再以 flow matching 去噪动作序列。因此世界预测对控制的作用发生在中间表示层，无须先 VAE 解码出 RGB 视频。

动作预训练时冻结 GE-Base-LF，只更新动作模块，以四幅 5 Hz 历史观测为条件，预测 **54 步、30 Hz** 动作序列；不加载未来视频作为该阶段监督，使用真实动作训练，16 张 A100 约三天。任务适配又分两步：先仅适配视频生成部分，完整 AgiBot 数据与任务子集混合，后者提高十倍采样权重；再只用任务数据联合更新视觉骨干和动作模块。两步各用八张 A100，约 12/36 小时。

部署采用 slow-fast 结构：视觉 DiT **一次前向/单步去噪**得到视觉 latent 并缓存，动作模块读取同一缓存执行五步去噪。论文报告单 RTX 4090 约 **200 ms 生成 54 步动作**。5 Hz 视觉更新、30 Hz 动作采样/执行、54 步 chunk 是不同量；不能理解成每秒从新观测运行 30 次完整网络。也不能把“无需显式视频生成”理解为彻底删掉视觉未来 token：§3.3 仍描述从高斯初始化隐状态得到单步预测性 latent。

GE-Act 正文的动作接口描述不如 GE-Sim 明确，不能据引言中的 torque 一词统一宣称输出力矩。现有代码 README 提供 joint/delta-joint 数据统计接口；实际复现需固定控制空间、状态定义与数据配置，尤其不能把下一节 GE-Sim 的末端位姿表示直接替换到策略中。

## 4. 闭环结果与消融：哪些结论有数字支持

§3.4 的 G1 真机包含做三明治、倒茶、擦桌子、微波炉、传送带装洗衣液五类任务，图 8 比较 GE-Act slow/fast 与 VLA。所有模型用同一任务示范微调。指标有**逐子步骤 SR**与**最终 E2E**；E2E 允许执行过程中重复尝试某一步，因此可比一次性子步骤成功率高，不能将两种曲线互换。

最可审计的真机消融是表 1：固定位置红圆柱放纸杯，**305 个示范、各训练 40K steps**。

| 初始化/适配，有本体状态 | E2E | 子步骤 SR |
|---|---:|---:|
| 无 AgiBot 领域视频预训练、无任务视频适配 | 0.15 | 0.05 |
| GE-Base 领域预训练，无任务视频适配 | **0.81** | **0.64** |
| GE-Base 领域预训练，再做任务视频适配 | **0.89** | **0.76** |

最后一行去掉本体状态后为 E2E/SR **0.37/0.37**。它支持领域预训练、状态与任务适配在此任务中的作用。表头 `VidAda` 是任务视频适配；邻近正文将最终提升写作“与通用视频预训练结合”，表述不够一致，因此以上按表头解释。不能据单个固定位置任务推广成任意场景的普遍增益。

跨本体是**少样本适配**：Agilex 两种折叠任务每种 250 个示范、约一小时；双 Franka 折布也是 250 个示范。先适配视频骨干，再因动作语义不同而从头训练新动作头，不是拿 G1 策略零样本直接部署。RoboTwin 四任务用总计 200 示范联合微调，而 π0/GO-1 对照分别做单任务适配；图 11 中 GE 三项更好，lift pot 略低。两种训练组织不同，应连同结果一起记录。

这些结果证明所测真机任务可闭环运行，但 v3 没有充分披露所有主图对应 rollout 分母、训练 seed 及区间；不从柱高反推显著性，也不把局部消融的 89% 当作整个五任务基准总成功率。

## 5. GE-Sim 与 EWMBench 的能力边界

GE-Sim 从 MR 初始化，给定动作和历史观测预测视频。对双臂用每步 14 维末端位姿/夹爪表示；Pose2Image 利用**相机内外参**将末端位置及旋转坐标轴投影到图像，与观测分别 VAE 编码后相加；另一支编码相邻位姿差，经 cross-attention 注入。这一路明确需要标定，但未要求输入场景深度。训练增加失败、未完成与次优轨迹，以视频 flow-matching loss 更新模型，冻结 VAE/CLIP。

所谓闭环仿真是策略→动作→GE-Sim 生成图像→策略再次动作。它仍可能生成不符合真实接触动力学的结果。表 2 中 LTX/COSMOS2 变体 PSNR 为 **19.9/20.7**，动态一致性 DYN 为 **0.78/0.85**；这些是视频指标，不能替代真机成功率或真实碰撞/力测量。

EWMBench 从测试集选十个训练任务之外的任务，每任务 100 视频；评价场景特征稳定、检测到的末端轨迹、指令语义等。轨迹评价为每指令生成三次后选与参考轨迹空间距离最小的一次，属于 **best-of-3**；不能与单次生成成绩混排。人类偏好一致性评估也只是部分代理验证，并未证明神经仿真器能可靠给任意策略排序。

## 6. 开源、Fast-WAM 关系及跨视角启发

[官方仓库](https://github.com/AgibotTech/Genie-Envisioner-V1) 有 GE-Base 预训练、GE-Act 适配/部署、仿真评测入口，链接 Base-fast/slow、GE-Sim 和 CALVIN 策略权重，也链接 AgiBotWorld/EWMBench 数据。论文自采各平台任务数据的完整发布范围未核实。仓库现叫 **Genie-Envisioner-V1**，README 同时列出 2026 年 GE-Act/GE-Sim v2 新闻；它们不能算作这份 v3 论文原始能力或复现结果。

GE 是 Fast-WAM“无需在线完整视频合成”讨论的重要邻近方案，但 GE 仍执行单步视觉预测并缓存，不能等同于 Fast-WAM 删除未来生成路径。对跨视角研究，值得借鉴的是稀疏 cross-view attention；尚缺少的是相机位姿留出 split、无标定测试和闭环性能的因果验证。多视图画面看起来相符不等于几何正确，更不等于换相机策略不变。若比较不同视角的动作，须统一物理状态与本体动作坐标；视角独有像素/遮挡应允许不同。
