# 评测协议草案：WAM 的跨视角一致性

状态：**调研阶段草案，尚未冻结、尚未执行**。本文件将来负责固定评测规则；当前缺少实际 baseline、算力、训练数据和代码提交，不伪装成已确定的正式实验协议。

## 1. 在实验前明确主张

两条路线分别评估，允许同一方法涉及两者，但不可混用结论：

| 主张 | 主指标 | 辅助指标 |
|---|---|---|
| 相机变化后策略仍然有效 | held-out viewpoint 闭环成功率及其相对对照差值 | 分布内成功率、动作兼容性、延迟、失败类别 |
| 多视角未来视频描述一致世界 | 几何/跨视角一致性及动作条件遵循 | 视频质量、逐视角结果；若声称帮助控制，另加闭环成功率 |

## 2. 数据与划分

优先从 LIBERO / LIBERO-Plus 做受控仿真准备；双臂或三视角视频可考虑 RoboTwin 2.0 / TriWorldBench。来源与用途见 [基准说明](benchmarks.md)。最终选择需在运行前记录。

- 保存模拟器和任务版本、数据文件hash、轨迹/状态/相机ID、同步方式、动作坐标系与标准化统计。
- 先按 episode/trajectory、必要时 scene 划分，再分别渲染同状态多视角；训练不得读入测试视角标签或测试集统计。
- 相机集合明确分为训练、内插留出、外推留出，分别写出方位/俯仰/距离范围；不靠“随机分20%帧”模拟未见视角。
- 外部和腕部相机是否改变、是否缺失必须分别记录；同时改变多种因素另设组合实验。
- 演示状态、测试初始状态与闭环偏离后的恢复状态要区分。仅示范状态一致不证明恢复行为正确。

## 3. 对照组

| 对照 | 目的 |
|---|---|
| 原始 baseline 与官方设置 | 先确认实现和数据正确 |
| 相同配对数据、相同预算、无一致性项 | 分离配对数据暴露与一致性损失的收益 |
| 拟研究方法 | 仅改变指定机制，保持其他配置相同 |
| 训练分布匹配测试视角的参照 | 提供训练分布匹配时的经验性能参照；不构成严格性能上界，也不是未见视角泛化对照 |
| 适用时：不同约束对象/几何模块消融 | 区分动作、特征、视觉或几何约束的作用 |

只有方法本身需要未来生成时才报告它的未来生成消融；不要为凑表加与研究问题无关的模型。

## 4. 统计和汇报

- 运行前固定模型、checkpoint 选择规则、任务集、初始状态、种子、每条件episode数、终止与成功判据。预算允许时使用至少3个独立训练种子；若不足，明确估计范围。
- 所有对照共享评测初始条件；报告每任务与每视角结果，以及均值和绝对差值（百分点）。
- 成功率差值用配对episode或任务层面的合适区间估计；多帧来自同轨迹时不能当作独立样本。对任务泛化的主张应按任务聚类统计，只有固定任务结论则明确限制。
- 训练种子间变异与同模型episode采样变异分别报告；不要用大量episode掩盖仅一个训练种子。
- 同时报全部预先确定指标和无提升/变差的设置。生成基准的总分保留所有子项与权重。
- 延迟记录 p50/p95、硬件/视角/动作块/采样步数，以及图像预处理和通信是否计入；频率定义明确。

## 5. 中间过程检查与可视化

1. 从一条轨迹逐项核对 RGB 时间戳、proprio、动作块、未来监督；确认没有未来真值进入部署动作条件。
2. 对配对视角可视化同一状态与物体；核对坐标变换、图像缩放和内参更新。
3. 保存成功率随视角角度/距离变化的曲线，以及逐任务表。
4. 固定 5–10 条失败初始状态，展示同步多视角视频、执行动作、任务阶段和失败原因。
5. 若有几何指标，展示可见性mask与对应点/重投影，报告评估器失败率；不能只挑匹配成功样本。
