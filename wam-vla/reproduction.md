# 从调研进入复现

本轮完成复现准备，**没有复现结果**。按 research-workflow，先核对 baseline 和数据中间过程，再形成研究假设。不要用以下准备建议冒充已执行实验。

## 建议顺序

| 阶段 | 候选 | 为什么 | 开始前要核实 |
|---|---|---|---|
| 学习动作管线 | Diffusion Policy 或 OpenVLA 的一个公开小设置 | 看懂图像到动作、数据对齐和闭环 | 数据/权重、动作格式、环境版本；依据可用资源只选一个 |
| 主要 WAM baseline | Fast-WAM 原版 | 已有公开训练/评测入口，适合分离视频监督与测试想象 | 固定论文对应配置，区分 Optional-IDM/compile 等仓库新增内容 |
| 跨视角受控实验 | Fast-WAM + 明确的相机留出协议；或实现已充分公开的同类方法 | 将“视角是否变了”变成可检查变量 | paired control、坐标系、腕部相机与状态划分 |
| 生成几何路线 | PAIWorld / TriWorldBench 作为参考 | 明确多视角生成目标与评估项 | PAIWorld官方页目前 Code soon；TriWorldBench评估器依赖与数据权限 |

这不是算力承诺。Fast-WAM论文单卡推理延迟不代表单卡可按原配方训练；官方多GPU训练说明见[逐篇笔记](related-work/fast-wam.md)。DreamZero 的数据规模和硬件设置也不宜直接当作初学者的第一项完整预训练任务。[DreamZero笔记](related-work/dreamzero.md)。

## 首次复现必须留什么

- 论文版本、仓库URL和commit、环境锁定、模型/数据版本与许可。
- 输入输出形状、动作频率/坐标/归一化、相机与时间同步的逐条核验。
- 官方评测指令及所有修改；指标口径一致后再比较论文值。
- 运行日志、随机种子、逐任务结果、固定失败样本、显存/时间。
- 原论文值和本机值分列；失败原因不得用猜测补成结论。
